# QymCAD MCP

Independent MCP integration for [QymCAD](https://github.com/QymIs-Tech/QymCAD), with native parametric modeling and two-way synchronization with the desktop window. Windows x64, Python 3.12+, AGPL-3.0-or-later. Experimental release; see [validation and known limitations](VALIDATION.md).

MCP — стандарт, по которому ИИ вызывает функции программы и получает результат. Здесь сервер выполняет команды настоящего ядра QymCAD/Open CASCADE. С флагом `--live` результат появляется в открытом окне CAD.

## Установка Windows-пакета

1. Распакуйте `QymCAD-MCP-Windows.zip`.
2. Выполните `setup.ps1`: он создаст Python-окружение и конфигурацию.
3. `open_gui.ps1` открывает QymCAD с подключением к MCP.
4. Для Codex выполните `install_codex.ps1`. Для другого клиента используйте созданный `mcp-config.json`.

Клиент сам запускает `server.py` через стандартные потоки. `start.ps1` также подходит как команда запуска. При ручном запуске он ждёт MCP-запросов. Локальные пути генерируются при установке и не входят в репозиторий.

## Живая работа

Установщик добавляет `--live`. Первый запрос подключает связанное окно или запускает его. Обычный QymCAD без патча этого подключения не поддерживает.

- Перед чтением, изменением, сохранением и экспортом MCP получает текущий документ окна, включая несохранённые ручные правки.
- Геометрия рассчитывается в отдельном процессе. Результат применяется только при успехе и если документ в окне за это время не изменился.
- При конфликте команда возвращает ошибку: прочитайте `qymcad_inspect` и повторите действие.
- История общая: `qymcad_undo` и Ctrl+Z отменяют последнее действие, в том числе сделанное вручную.
- `qymcad_screenshot` возвращает настоящий снимок окна. `qymcad_fit_view` помещает модель в кадр.
- Перед командой MCP завершите редактирование эскиза, ввод числа или открытый диалог. Занятое окно вернёт ошибку.
- `qymcad_save_project` сохраняет **копию**. Ctrl+S сохраняет текущий файл окна. `qymcad_open_project` меняет его путь; новый документ сбрасывает путь.

При потере подтверждения от окна результат команды считается неизвестным: проверьте модель перед повтором. Отключение MCP не закрывает CAD и не удаляет его несохранённую модель. Без `--live` каждый MCP-клиент работает с отдельной моделью, которую нужно сохранить перед отключением.

## Возможности

21 инструмент в режиме окна; 19 в автономном режиме:

- состояние, дерево модели, создание/открытие проекта и отдельных деталей;
- параллелепипед, цилиндр, сфера, конус, тор;
- эскизы прямоугольника, окружности и многоугольника на XY/XZ/YZ или смещённой плоскости;
- выдавливание с добавлением/вычитанием/пересечением, вращение и объём по сечениям;
- скругление, фаска, перенос, переименование;
- параметры с формулами, изменение размеров, отмена;
- сохранение редактируемого `.qcad`, экспорт STL и STEP в миллиметрах;
- снимок окна и установка масштаба по модели.

`qymcad_inspect` возвращает ID, операции, размеры, точные объёмы, габариты, грани и рёбра. Новый примитив без `part_id` создаёт отдельную деталь; внутри указанной детали материал объединяется. Параллелепипед центрирован по X/Y и начинается от Z=0.

## Границы доступа

Сервер использует stdio и не открывает сетевой порт. Связь с окном идёт через приватный локальный каталог `.live`. Запросы имеют срок действия, а изменения проверяют ревизию документа. Произвольного исполнения кода через MCP нет.

Файлы MCP ограничены `models` либо каталогом `--workspace`, перезапись требует `overwrite=true`, входные проекты — не более 100 МБ. Пользователь может открыть другой файл через интерфейс CAD: подключённому MCP становится доступен текущий документ этого окна.

## Версия и ограничения

Основа: QymCAD `3ee0d1383accbf9cf34ad0bf8403215f9885dcbe` от 10.10.2026. Изменения окна находятся в `patches/live-window.patch`. Формат QymCAD развивается; совместимость с произвольной другой версией не гарантирована. Импортированным телам нужны сохранённые B-rep.

Не все инструменты CAD представлены в MCP: пока нет сопряжений сборки, CAM и отдельной команды размерных ограничений эскиза. Их можно применять в окне. Linux/macOS и физическая 3D-печать этим проектом не проверяются.

## Сборка

Нужны Git, Rust stable, Visual Studio Build Tools с C++ workload и Windows SDK.

```powershell
./setup.ps1
./.venv/Scripts/python.exe prepare_sources.py
./.venv/Scripts/python.exe setup_occt.py
./build.ps1
./build_gui.ps1
./open_gui.ps1
```

`prepare_sources.py` получает фиксированные исходники в соседний каталог `QymCAD` и применяет патч. В готовом архиве исходная версия приложена в `sources/QymCAD-3ee0d138.zip`. Для SDK Open CASCADE 7.8.1 и официальных DLL проверяется SHA-256. При запуске нужны DLL из `vendor/qymcad-app`; SDK используется только при сборке.

Python: `./.venv/Scripts/python.exe -m pytest tests -q`.
Проверка настоящего цикла GUI и клавиатурного Ctrl+Z: `cargo test --manifest-path ../QymCAD/Cargo.toml -p qymcad --test live_bridge` (переменные OCCT/PATH берите из `build_gui.ps1`).

Публикация нужна, чтобы другие могли установить, проверить и улучшить интеграцию. Для локальной работы она не требуется. Это независимый проект, не официальный сервер QymCAD. Лицензии перечислены в `THIRD-PARTY-NOTICES.md`.
